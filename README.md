# 💻 TALK TO COMPUTER — Retro Terminal Game

A nostalgic, sassy 90s-style **"Talk to Computer"** terminal web game built in **pure HTML, CSS, and Vanilla JavaScript**. Features built-in privacy & ethics guardrails, a live Suspicion Meter, and a 5-second Firewall Lockdown mode—with zero APIs and zero external dependencies.

### 🎮 Play Live
👉 **[Launch Talk to Computer](https://rahulcodes-ai.github.io/talk-to-computer/)**

### ✨ Key Features
- **🛡️ Strict Privacy & Ethics Firewall:** Automatically detects and blocks hacking, personal data, and unethical prompts with sassy, humorous refusals.
- **🚨 Live Suspicion Meter (0%–100%):** Tracks shady prompts in real time and triggers a 5-second **Firewall Lockdown** at 100%.
- **⚡ 1-Click Quick Prompts:** Instantly test jokes, roasts, security blocks, and privacy checks.
- **🔒 100% Client-Side & Private:** Runs completely in your browser—zero tracking, zero servers, zero API keys.

### 🛠️ Tech Stack
- Pure HTML5, CSS3, Vanilla JavaScript (Single-file architecture)
- Hosted via **GitHub Pages**
